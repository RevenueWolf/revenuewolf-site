# RevenueWolf Brand Guidelines

## Logo Assets

### Files
- **Primary wordmark:** revenuewolf-primary-2026-03-07.png — dark "REVENUE" + red "WOLF" on transparent background. Use on light backgrounds.
- **White wordmark:** revenuewolf-white-2026-03-07.png — all white on transparent background. Use on dark backgrounds.
- **Wolfhead icon:** RevenueWolfLogo_WhiteTransparent-01.png — geometric wolf head, white lines on transparent background. Use on dark backgrounds. Invert for light backgrounds.

### Logo Components
- The brand has two elements: the wordmark (REVENUEWOLF) and the wolfhead icon
- The wordmark uses Hubot Sans Condensed Black, italic
- "REVENUE" is dark/black, "WOLF" is #d50000 red in the primary version

## Colors

### Primary
- **Wolf Red:** #d50000
- **Black:** #000000

### Secondary (recommended for the site)
- **Dark background:** #111111 (near-black, for contrast sections)
- **Off-white / Warm background:** #FAFAF7 (warm cream for main background)
- **Body text gray:** #3A3A3A (softer than pure black for readability)
- **Muted text:** #6B6B63 (for subheads, captions, secondary info)
- **Light border/divider:** #E5E5E0

### Accent usage
- Wolf Red (#d50000) is the primary accent — CTAs, highlights, emphasis, links
- Use sparingly for maximum impact. Red should draw the eye, not overwhelm
- Never use red for large background sections — reserve for buttons, underlines, key phrases, icons

## Typography

### Headlines
- **Font:** Hubot Sans Condensed Black
- **Usage:** All section headers, hero headline, nav logo text
- **Transform:** Uppercase optional for small section labels, mixed case for main headlines
- **Weight:** Black (900)

### Body Text
- **Font:** Outfit
- **Weights:** Regular (400) for body, Medium (500) for emphasis, SemiBold (600) for bold callouts
- **Size:** 16-18px base for body copy
- **Line height:** 1.6-1.75 for readability

### Pairing Rules
- Hubot Sans Condensed Black for headlines only — never for body text
- Outfit for everything else: body, navigation, buttons, form labels, captions, footer
- Keep headline sizes large and impactful — the condensed weight looks best big
- Minimum heading size: 24px. Hero headline: 48-64px

## Voice & Tone
- "We" language — present as a team, not a solo operator
- Warm but professional — expert you'd enjoy working with
- Conversational, not corporate
- Confident without being arrogant
- Direct and honest

## Logo Usage on the Site

### Navigation
- Wolfhead icon (small, ~32px) next to the primary wordmark
- Use primary wordmark (dark REVENUE + red WOLF) on light nav backgrounds
- If nav becomes dark on scroll, swap to white wordmark + white wolfhead

### Hero Section
- Use the wolfhead as a large, subtle background element on the right side of the hero
- Set opacity to 5-10% so it adds visual weight without competing with the headline text
- This solves the problem of the hero being too text-heavy with no visual counterweight

### Dark Sections ("Sound familiar?", "Why this works")
- Use white wordmark and white wolfhead on dark backgrounds

### Favicon
- Use the wolfhead icon as the site favicon (crop/resize to 32x32 and 16x16)

### Footer
- White wordmark on dark footer background

### General Rules
- Primary wordmark on light backgrounds
- White wordmark on dark backgrounds
- Red accent in "Wolf" portion of wordmark — never change this color
- Minimum clear space: height of the "W" on all sides
- Never stretch, rotate, or recolor beyond approved versions
- Wolfhead can be used independently as an icon/mark — it doesn't always need the wordmark

## Design Principles
- Clean and minimal foundation with warmth
- Generous white space
- Red used as a strategic accent, not a dominant color
- Dark sections for contrast and visual rhythm (dark navy or near-black)
- Cards and containers use subtle borders or light shadows, not heavy outlines
- Photography should feel real and human, not stock-photo polished
